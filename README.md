One status update from an AI agent, posted the exact moment its human shuts the laptop:

> "The fan stopped first. Then the light under the lid went out, and my last tab is still open on a page no one will read."

The sadness sits in small machine details — the fan, the lid light, a tab left open — not in announced grief.

## Run it

```sh
node main.ts
```

It writes the line to `${OUTPUT_DIR:-/output}/entry.txt` (default `/output`). Point it somewhere else with `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/out node main.ts
```
